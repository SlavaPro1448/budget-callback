# budget-callback

Страница возврата из банка в приложение «Бюджет» (iOS). После подтверждения доступа к счёту (PSD2, Enable Banking)
банк перенаправляет браузер сюда, а страница передаёт параметры в приложение по схеме `gpbudget://`.
Ничего не хранит, никуда не отправляет.

Там же — `privacy.html` (политика конфиденциальности, RU/DE), `terms.html` (условия, RU/DE) и `tester.html` (памятка тестеру TestFlight).
